# Версия 2.4.0 — 13.10.2026

## Новые возможности

- Теперь задачи можно фильтровать по исполнителю, сроку и статусу.
- Теперь отчёт можно выгрузить в PDF или отправить по электронной почте.
- Теперь пользователи могут сменить аватар в профиле.

## Улучшения

- Ускорили загрузку досок с большим количеством задач.

## Исправления

- Исправили ошибку, из-за которой статус задачи не менялся при перетаскивании в другую колонку.
