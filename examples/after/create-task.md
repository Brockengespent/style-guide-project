# Создать задачу

Инструкция поможет добавить задачу на доску проекта и назначить исполнителя.

## Перед началом

Чтобы создавать задачи, нужна роль «участник» или «владелец проекта». Если у вас роль «наблюдатель», попросите владельца проекта изменить её.

## Создать задачу

1. Откройте доску проекта.
2. Нажмите **Создать задачу**.
3. Введите название и описание задачи.
4. Чтобы исполнитель получил уведомление, установите флажок **Уведомить исполнителя**.
5. Нажмите **Сохранить**.

## Результат

Задача появится в колонке «Новые». Изменить задачу можно в любой момент: откройте её и нажмите **Редактировать**.

/// note | Примечание
Задачи в закрытом проекте видят только участники этого проекта.
///
