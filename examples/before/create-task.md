# Как создать новую Задачу?

Данная инструкция описывает процесс создания задачи в системе Делотрек. Для того чтобы создать задачу, Вам необходимо иметь права участника проекта, в противном случае кнопка создания задачи будет недоступна и Вы не сможете осуществить данное действие!

* Откройте доску проекта
* Кликните по кнопке "Создать задачу" - она находится в правом верхнем углу.
* В открывшейся форме введите название таски и описание
* Поставьте галочку "Уведомить исполнителя", если нужно
* Нажмите Сохранить

Задача будет создана и отобразится в колонке "Новые". Стоит отметить, что задача может быть отредактирована в любой момент.

**ВАЖНО:** если задача создается в закрытом проекте, ее увидят только участники проекта!!
