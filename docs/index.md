# Руководство по стилю документации ДелоТрек

Это руководство описывает, как писать и оформлять документацию сервиса ДелоТрек. ДелоТрек — веб-сервис для планирования задач в командах. Руководство помогает авторам писать одинаково, а читателям — быстро находить ответы.

/// note | Объект руководства
Руководство распространяется на всю документацию продукта. Команда ведёт её в Markdown по подходу Docs as Code: тексты лежат в Git-репозитории, проходят ревью и автоматические проверки, а сайт собирается из исходников.
///

## Для кого это руководство

- Технические писатели — основные авторы документации.
- Разработчики — пишут README, описания API и комментарии к выпускам.
- Аналитики и тестировщики — готовят инструкции и справочные статьи.
- Ревьюеры — проверяют изменения в документации по этим правилам.

## Основные принципы

1. **Польза для читателя.** Каждый документ отвечает на конкретный вопрос читателя и помогает решить задачу.
2. **Простота.** Пишем короткими предложениями, без канцелярита и лишних терминов.
3. **Единообразие.** Одинаковые вещи называем и оформляем одинаково во всех документах.
4. **Точность.** Названия элементов интерфейса, команды и значения совпадают с продуктом.
5. **Проверяемость.** Всё, что можно проверить автоматически, проверяет линтер в CI.

## Как пользоваться руководством

- Перед написанием документа выберите [шаблон](doc-templates/index.md) и заполните его.
- Сверяйтесь с разделами о [стиле изложения](voice-and-tone.md), [орфографии и пунктуации](spelling-punctuation.md) и [оформлении текста](text-formatting.md).
- Перед отправкой изменений запустите линтеры: `npm run lint`.
- Если правила не хватает или оно мешает, предложите изменение через Pull Request.

## Как устроены правила

У каждого правила есть код, формулировка, пример и способ проверки. Код правила состоит из префикса раздела и номера, например **СТ-3** — третье правило раздела «Стиль изложения». На код удобно ссылаться в комментариях к ревью.

| Префикс | Раздел |

| СТ | [Стиль изложения](voice-and-tone.md) |
| ОП | [Орфография и пунктуация](spelling-punctuation.md) |
| ОФ | [Оформление текста](text-formatting.md) |
| ИЗ | [Скриншоты и схемы](images.md) |

| ТР | [Точечные рекомендации](recommendations.md) |

| ГЛ | [Словарь и глоссарий](glossary.md) |

Пометка «Линтер» в правиле означает, что нарушение находит автоматическая проверка. Пометка «Ревью» — что правило проверяет человек.
