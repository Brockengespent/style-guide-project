# Шаблон описания метода API

Описание метода помогает разработчику интеграции быстро отправить правильный запрос и обработать ответ.

## Структура

1. **Заголовок** — что делает метод, глагол в инфинитиве: «Получить список задач».
2. **Метод и путь** — HTTP-метод и адрес в блоке кода.
3. **Описание** — 1–2 предложения: когда использовать метод.
4. **Параметры запроса** — таблица.
5. **Пример запроса** и **пример ответа** — блоки кода с подсветкой.
6. **Коды ответов** — таблица с кодами и причинами ошибок.

## Шаблон

````markdown
# [Глагол в инфинитиве + объект]

```http
GET /api/v1/[ресурс]
```

[Когда использовать метод.]

## Параметры запроса

| Параметр | Тип | Обязательный | Описание |
| --- | --- | --- | --- |
| [name] | [string] | [Да или Нет] | [Описание] |

## Пример запроса

```bash
curl -H "Authorization: Bearer <токен>" https://api.example.com/api/v1/[ресурс]
```

## Пример ответа

```json
{
  "id": 42,
  "title": "Подготовить отчёт"
}
```

## Коды ответов

| Код | Значение |
| --- | --- |
| 200 | Запрос выполнен |
| 401 | Токен не передан или истёк |
````
