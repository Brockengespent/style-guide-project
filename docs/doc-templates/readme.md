# Шаблон README

README — первый документ, который видит разработчик в репозитории. Он отвечает на вопросы: что это, как запустить и куда обращаться.

## Структура

1. **Название и описание** — одно предложение о назначении сервиса.
2. **Быстрый старт** — минимальные команды для запуска.
3. **Требования** — версии языков, инструментов и сервисов.
4. **Конфигурация** — переменные окружения в таблице.
5. **Разработка** — как запустить тесты и линтеры.
6. **Контакты** — команда-владелец и канал для вопросов.
