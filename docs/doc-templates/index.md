# Шаблоны документов

Шаблон задаёт обязательную структуру документа определённого вида. Начинайте новый документ с копирования шаблона: так документы одного вида выглядят одинаково, а автор не забывает важные разделы.

| Шаблон | Когда использовать |
| --- | --- |
| [Инструкция](how-to.md) | Нужно объяснить, как выполнить конкретную задачу по шагам |
| [Справочная статья](reference.md) | Нужно описать возможность, настройку или понятие |
| [Описание метода API](api-method.md) | Нужно описать метод REST API для разработчиков интеграций |
| [README](readme.md) | Создаётся новый репозиторий или сервис |
| [Примечания к выпуску](release-notes.md) | Выходит новая версия продукта |

## Общие правила для всех шаблонов

- Удаляйте из готового документа подсказки в квадратных скобках.
- Не удаляйте обязательные разделы. Если раздел не нужен, обсудите это на ревью.
- Необязательные разделы помечены в шаблоне словом «необязательно».
