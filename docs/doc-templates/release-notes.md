# Шаблон примечаний к выпуску

Примечания к выпуску рассказывают пользователям и поддержке, что изменилось в новой версии продукта.

## Правила

- Пишем о пользе для читателя, а не о внутренних задачах: «Теперь задачи можно фильтровать по исполнителю», а не «Добавлен фильтр в TaskListComponent».
- Каждое изменение — один пункт маркированного списка, начинается с глагола или со слова «Теперь».
- Группируем изменения по типам: новые возможности, улучшения, исправления.
- Номер версии пишем по семантическому версионированию: `2.4.0`.

## Шаблон

```markdown
# Версия [X.Y.Z] — [ДД.ММ.ГГГГ]

## Новые возможности

- [Теперь можно ...]

## Улучшения

- [Ускорили ...]

## Исправления

- [Исправили ошибку, из-за которой ...]
```
